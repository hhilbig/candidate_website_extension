# Archived development scripts

These scripts come from the development of the extracted-variables release (August 22 to September 15, 2026): endorsement rounds 2 and 3, the recall-40 and independent-40 checks, the line ledger, and the 40-parent pilot.
Version 4.0 is published, and no current script imports these files.
They stay here as a record. They were moved from `scripts/` and `scripts/hive/` on October 4, 2026, so paths inside them still point to the old locations.
Their tests are in `tests/archive/`, which pytest skips. Several tests read build folders that are now only on mac2, in `~/backups/candidate_website_extension/build_archive_20261004/`.
