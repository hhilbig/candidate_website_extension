# Session logs

Per-session work notes. One file per session, named
`YYYY-MM-DD_short-task.md` (mirror the plan name when there is one).
Template at `templates/session-log.md`.

Write a log after plan approval, at major decision points, and at
wrap-up. Plain English, concise — the point is to make the next session
pick up cleanly, not to produce prose.
