# Archive-It expansion adjudication

This completed review batch contains five grade-A campaign domains from the
first promoted Archive-It collections: Birmingham 2017, Grand Rapids 2019, and
Cleveland 2021. Hanno accepted all five on 2026-08-25. Three are new covered
candidate-years; the two Cleveland candidates were already in the legacy
baseline.

The canonical export is
`mayoral_url_archiveit_expansion_adjudication_20260825_results.json`. The source
API responses are frozen under
`data/municipal_discovery/archiveit/source_payloads/`.

The imported files are `adjudication.csv`, `adjudicated_claims.csv`, and
`adjudication_summary.json`. They remain separate from the completed 33-item
Archive-It adjudication package.
