# Mayoral URL data outreach drafts

## Use and approval rule

These drafts request historical election records for research. No message can
be sent until Hanno approves the exact text and recipient.

The attached sample will contain 100 masked candidate records. It will omit
candidate names. It will retain a masked ID, city, state, office, election year,
election month, and election-round status.

## BallotReady or CivicEngine

**Target:** BallotReady data-products team through its official contact form  
**Subject:** Historical local candidate website data sample request

Hello,

I am building an academic dataset of campaign websites used by candidates for
mayor in large U.S. cities. The project covers elections from 2000 through 2021.

Could you evaluate the attached masked sample and return any event-specific
historical records that you hold for these candidacies? We need the candidate
identifier, ballot name, office, jurisdiction, election date and round, campaign
website as observed for that election, observation date, and source provenance.

Please also confirm whether historical website values remain versioned or can be
overwritten by a candidate's current profile. If a usable historical sample is
available, please provide the license terms and a quote for the covered universe.

Best,
Hanno Hilbig

## Municipal public-record request

**Target:** The election records officer for one approved city  
**Subject:** Historical municipal candidate contact records request

Hello,

I request the native electronic candidate contact lists, filing exports, voter
guide data, or election-management extracts for the specified mayoral elections.

Please include ballot name, office sought, election date and round, campaign
website, campaign email, phone, committee name or ID, treasurer, and any retained
historical versions. Please provide CSV, Excel, database, JSON, or the original
electronic files when available. A PDF copy is also useful when no native file
remains.

Please include the data dictionary and records-retention schedule. If the records
no longer exist, please state the earliest year that remains available.

Best,
Hanno Hilbig
